# PollStream Survey Workflow - Полное руководство

## 📋 Обзор

Реализована полная система управления опросами с 4-этапным процессом:

1. **Создание опроса** (create_survey.html) - Конструктор вопросов
2. **Настройки** (survey_settings.html) - Конфигурация параметров
3. **Сбор ответов** (survey_responses.html) - Распространение и статистика
4. **Результаты** (survey_results.html) - Анализ и экспорт

## 🔧 Установка и настройка

### Шаг 1: Миграции БД (уже выполнены)

```bash
python manage.py makemigrations
python manage.py migrate
```

Миграция `0003_survey_allow_edit_after_submit_survey_description_and_more` содержит:
- 11 новых полей в таблице Survey
- Новую таблицу SurveyLink для управления ссылками

### Шаг 2: Запуск сервера разработки

```bash
python manage.py runserver
```

## 📱 Использование

### Для создателя опроса:

1. **Перейти на главную страницу** (/)
2. **Нажать "Создать новый опрос"**
3. **Добавить вопросы** на странице конструктора
4. **Сохранить опрос** - система автоматически перенаправит на страницу настроек

### На странице настроек (/survey/{id}/settings/):
- Установить название и описание
- Выбрать уровень видимости (Приватная/По ссылке/Публичная)
- Настроить ограничения на количество ответов
- Включить/отключить элементы отображения (прогресс-бар, номера вопросов и т.д.)
- Сохранить параметры
- Перейти к сбору ответов

### На странице сбора ответов (/survey/{id}/responses/):
- Скопировать ссылку на опрос
- Скачать QR-код для мобильных устройств
- Просмотреть текущее количество ответов
- Увидеть последние полученные ответы

### На странице результатов (/survey/{id}/results/):
- График ответов по датам (Chart.js)
- Таблица со всеми ответами
- Просмотр деталей каждого ответа
- Экспорт результатов в CSV

## 🎨 Дизайн и стиль

Все новые страницы:
- Используют **Tailwind CSS** для оформления (согласованно с create_survey.html)
- Имеют одинаковую структуру навигации с шагами
- Синхронизированы с цветовой схемой проекта (индиго-600)
- Поддерживают полносценный UI на всех размерах экрана

### Цветовая схема:
- Основной цвет: `bg-indigo-600`
- Фон: `bg-gray-50`
- Текст: `text-gray-900`, `text-gray-700`

## 💾 Сохранение данных

### На странице настроек:
- Все параметры сохраняются через POST запрос
- Данные хранятся в базе данных Survey
- JavaScript показывает статус сохранения

### На странице сбора ответов:
- Автоматически создаётся SurveyLink при первом ви­сите
- Каждый ответ сохраняется как SurveyResponse
- JSON структура ответов: `{question_id: answer}`

## 🔐 Безопасность

- Все не-анониме страницы требуют аутентификации (`@login_required`)
- CSRF защита на всех POST запросах
- Проверка прав доступа (только автор может редактировать опрос)
- Токены для ссылок на опросы (модель SurveyLink)

## 🚀 Развёртывание

### На Production:

1. Собрать статические файлы:
```bash
python manage.py collectstatic --noinput
```

2. Убедиться, что `DEBUG = False` в settings.py

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Выполнить миграции:
```bash
python manage.py migrate
```

5. Запустить с gunicorn:
```bash
gunicorn PollStream.wsgi:application
```
